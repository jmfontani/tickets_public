# Taxonomía Universal de Productos — 3 Niveles

Diseñada para funcionar con cualquier supermercado (Mercadona, Carrefour, Día, Lidl...), no solo Mercadona. El matching es por keywords en el nombre del producto, independientemente de la tienda.

## Estructura jerárquica

```
Categoría (1) → Subcategoría (2) → Producto normalizado (3)
```

Ejemplo: `Alimentación → Lácteos y huevos → Leche`

## Reglas de matching

El motor de normalización usa **keyword matching case-insensitive** con prioridad:
1. Reglas específicas (marca + tipo): "NESCAFÉ" → Café
2. Reglas por tipo: "LECHE" → Lácteos
3. Fallback: "Otros → Varios"

Las reglas son **store-agnostic**: funcionan con cualquier formato de ticket (Mercadona, Carrefour, Día, Lidl, etc.) porque se basan en el nombre del producto, no en códigos de tienda.

## Esquema de BD propuesto

```sql
-- Nueva tabla de taxonomía universal
CREATE TABLE taxonomy (
    id INTEGER PRIMARY KEY,
    keyword TEXT NOT NULL,        -- keyword para matching (upper)
    categoria TEXT NOT NULL,      -- nivel 1
    subcategoria TEXT NOT NULL,   -- nivel 2
    producto_norm TEXT NOT NULL,  -- nivel 3
    priority INTEGER DEFAULT 0   -- prioridad de matching
);

-- Modificación de line_items
ALTER TABLE line_items ADD COLUMN categoria_general TEXT;
ALTER TABLE line_items ADD COLUMN subcategoria TEXT;
-- categoria existente pasa a ser subcategoria o se migra
```
